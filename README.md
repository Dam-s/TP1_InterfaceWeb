# 🛠️ Application Web de Gestion de Projets - PIW2025

Ce projet est une application web développée avec **Django**, destinée à faciliter la gestion des projets, le suivi des heures de travail des employés, ainsi que l’administration des ressources. Elle offre une interface claire pour les employés et les administrateurs avec un système d’authentification sécurisé et une base de données hébergée localement via XAMPP.

---

## 🚀 Fonctionnalités principales

### 1. Authentification des Employés
- Connexion sécurisée avec nom d’utilisateur et mot de passe.
- Interface personnalisée selon le rôle.
- Les employés accèdent uniquement à leurs projets et heures.

### 2. Gestion des Projets et des Heures
- Création de projets par l’administrateur.
- Assignation des employés aux projets.
- Enregistrement des heures de travail par les employés via formulaire.

### 3. Interface Administrateur
- Gestion complète des employés, projets et heures via le panneau Django admin ou des vues personnalisées.
- Création de nouveaux employés avec permissions adaptées.

### 4. Hébergement de la Base de Données
- Utilisation de **MySQL avec XAMPP**.
- Configuration de la base dans `settings.py`.

### 5. Sécurité et Permissions
- Accès restreint selon les rôles (employé vs administrateur).
- Système de permissions intégré pour protéger les données sensibles.

---

## 🧱 Technologies utilisées

- **Python 3.13**
- **Django 4.x**
- **Bootstrap 5** (interface responsive)
- **XAMPP + MySQL** (base de données locale)
- **Visual Studio Code** (environnement de développement)
